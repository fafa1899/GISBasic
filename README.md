# 《GIS基础原理与技术实践》配套资源

> 📘 作者：程雷  
> 📚 出版社：北京航空航天大学出版社  
> 📅 出版时间：2025年11月  

本仓库为《GIS基础原理与技术实践》一书的官方配套资源库，提供书中所有**可运行示例代码、实验数据、补充资料及勘误更新**，助力读者深入理解 GIS 核心原理并快速上手开发实践。

---

## 💻 示例代码

本书提供多语言版本的完整示例代码，覆盖主流 GIS 开发技术栈。所有代码按编程语言分类存放于仓库根目录下，具体包括：

- **`Cpp/`**：C/C++ 实现（书中主讲语言），[使用说明](./Cpp/README.md)  
- **`CSharp/`**：C# 实现，[使用说明](./CSharp/README.md)  
- **`Java/`**：Java 实现，[使用说明](./Java/README.md)  
- **`JavaScript/`**：前端 JavaScript 实现，[使用说明](./JavaScript/README.md)  
- **`Python/`**：Python 实现，[使用说明](./Python/README.md)  

各语言版本在功能上尽可能与书中章节内容保持一致，便于不同技术背景的读者对照学习。但由于各语言生态和库支持的差异，部分功能暂无法完全对齐。

> ⚠️ 当前 C/C++ 版本已完整实现，其余语言的示例正在持续完善中，敬请期待！

## 🗃️ 实验数据

本书所用的实验数据统一存放在仓库根目录的 **`Data/`** 目录中。  

由于前端开发的资源加载限制，部分专用于 JavaScript 示例的数据已放置在 **`JavaScript/public/`** 目录下，以便直接通过 Web 服务访问。
